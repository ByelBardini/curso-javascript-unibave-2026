Aula 03 - Exercícios

O código vai no arquivo script.js.

Exercício 01 - Notas da turma (console)

Este exercício não mexe na página: tudo acontece no console.log. Abra o console do navegador com F12 para ver a saída.

  1. Crie um array notas com pelo menos cinco números e mostre o array inteiro no console.
  2. Mostre a primeira nota, a última (sem escrever o número da posição na mão) e quantas notas existem.
  3. Percorra o array com for e mostre cada nota no formato Nota 1: 8.5 (o aluno conta a partir do 1, o array não).
  4. Some todas as notas e mostre a média com duas casas decimais.
  5. Desafio: descubra a maior e a menor nota do array usando só for e if.

Para a média você precisa de uma variável que sobreviva entre as voltas do laço: ela nasce antes do for, não dentro dele. No desafio, pense em quem é o "maior" antes de a primeira comparação acontecer.

Exercício 02 - Lista de tarefas

O array é a fonte da verdade: ninguém mexe na <ul> direto, a tela é sempre redesenhada a partir do array.

  1. Crie o array tarefas (vazio) e a função atualizarTela(), que recria um <li> para cada item, no formato [0] estudar.
  2. O botão adicionar coloca a tarefa digitada no fim do array (push) e chama atualizarTela().
  3. Não deixe adicionar tarefa vazia nem uma tarefa que já está na lista. O aviso vai no parágrafo de saída.
  4. O botão concluir remove a última tarefa (pop) e avisa qual foi removida.
  5. O botão de remover por posição usa splice, mas só depois de conferir se a posição digitada existe.
  6. Desafio: mostre embaixo da lista quantas tarefas existem e, quando o array estiver vazio, escreva Nenhuma tarefa por enquanto.


    Antes de criar os <li> novos, o que acontece com os antigos? Se a lista for crescendo em dobro a cada clique, está faltando uma linha no começo do atualizarTela().

    Exercício 03 - Ficha do produto (console)

    De volta ao console: aqui o assunto é objeto, e a página continua parada.

    1. Crie um objeto produto com as propriedades nome, preco, quantidade e disponivel.
    2. Mostre o nome usando ponto, o preço usando colchetes e o que aparece ao acessar uma propriedade que não existe.
    3. Dê um desconto de 10% no preço e crie a propriedade categoria em um objeto que já estava pronto.
    4. Percorra o objeto com for...in e mostre cada propriedade no formato preco = 3150.
    5. Faça uma cópia do produto com { ... }, mude o preço da cópia e mostre os dois no console para provar que o original ficou como estava.
    6. Desafio: adicione a propriedade fabricante, que é outro objeto com nome e cidade, e mostre só a cidade no console.

    Se depois de mudar a cópia o original também mudou, o que você fez foi dar outro nome para o mesmo objeto, e não copiar. Compare com o exemplo 03 da parte 02.

    Exercício 04 - Cadastro de filmes

    Junta as duas metades da aula: um array onde cada item é um objeto, com a tabela redesenhada a cada mudança.

    1. Crie o array filmes já com dois filmes. Cada filme é um objeto com titulo, ano e nota.
    2. atualizarTabela() percorre o array e monta uma linha (<tr>) por filme, com uma quarta coluna calculada por você: Bom quando a nota for 7 ou mais, Ruim quando for menor.
    3. O botão cadastrar lê os três campos, monta o objeto e coloca no array. Não deixe cadastrar com título vazio nem com um título repetido.
    4. procurarPorTitulo() percorre o array e devolve o objeto encontrado ou null. Ela não pode mexer na tela.
    5. O botão buscar usa essa função e mostra os dados do filme na saída; o botão remover usa splice na posição do filme encontrado.
    6. Desafio: mostre embaixo da tabela a média das notas e o título do filme com a maior nota.


    Título Ano Nota Situação

    A busca por um objeto não é com includes(): dois objetos com o mesmo conteúdo não são iguais para o JavaScript. Compare uma propriedade de cada item dentro de um for.
