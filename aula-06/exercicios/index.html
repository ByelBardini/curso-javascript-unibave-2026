Exercício 01 - Contador de visitas e tema escuro

A página precisa lembrar de duas coisas mesmo depois de recarregar (F5): quantas vezes ela foi aberta e qual tema o usuário escolheu.

  1. Assim que a página abre, busque a chave visitas no localStorage, some 1 e salve de novo. Na primeira vez ela não existe (null), então a contagem começa do zero.
  2. Mostre no parágrafo Você abriu esta página 3 vezes. Na primeira visita, escreva Primeira visita, seja bem-vindo!.
  3. O botão zerar apaga a chave visitas com removeItem e atualiza o parágrafo.
  4. O botão alternar tema coloca ou tira a classe escuro do body e salva a escolha na chave tema ("escuro" ou "claro"). Ao abrir a página, o tema salvo já precisa aparecer aplicado.
  5. Desafio: guarde também a data e hora de cada visita na chave ultimaVisita, usando new Date().toLocaleString(), e mostre Sua última visita foi em 14/10/2026, 19:30:00. Atenção: tem que mostrar a visita anterior, então leia o valor antes de salvar o novo.

O localStorage só guarda texto: o getItem devolve "3", não 3. Converta com Number() antes de somar, senão "3" + 1 vira "31". Para colocar e tirar a classe de uma vez existe o document.body.classList.toggle("escuro"), e o classList.contains("escuro") diz se ela está lá.

Exercício 02 - Lista de tarefas

Uma lista de tarefas que não se perde ao recarregar. Cada tarefa é um objeto com o texto e se já foi feita: { texto: "Estudar JavaScript", feita: false }. O array tarefas é a fonte da verdade, e o localStorage é só uma cópia dele.

  1. Ao abrir a página, busque a chave tarefas e transforme o texto em array com JSON.parse. Se não existir nada salvo, comece com um array vazio.
  2. Crie a função salvarTarefas(), que grava o array com JSON.stringify. Ela deve ser chamada toda vez que o array mudar.
  3. O botão adicionar coloca uma nova tarefa no array, com feita: false. Não aceite texto vazio (nem só espaços) e limpe o campo depois de adicionar.
  4. mostrarTarefas() cria um <li> por tarefa com os botões Concluir e Excluir. Concluir inverte o feita (tarefa feita ganha a classe feita e fica riscada) e excluir tira a tarefa do array com splice. Escreva também 2 de 5 tarefas concluídas.
  5. O botão limpar concluídas deixa no array só as tarefas que ainda não foram feitas.
  6. Desafio: adicione os filtros Todas, Pendentes e Concluídas, que só mudam o que aparece na tela (o array continua com tudo). O filtro escolhido também fica salvo no localStorage, então depois do F5 a lista volta com o mesmo filtro.

    Filtro (desafio):

    Para os botões de cada tarefa, monte o onclick com o índice na string do innerHTML: "<button onclick='concluirTarefa(" + i + ")'>Concluir</button>". trim() tira os espaços das pontas de um texto, e o filter() monta um array novo só com os itens que passam no teste. Abra F12 > Application > Local Storage para conferir o que está salvo, e apague a chave por lá se o JSON salvo quebrar.
